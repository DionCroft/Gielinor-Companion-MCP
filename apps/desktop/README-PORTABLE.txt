Gielinor Companion 1.2.0 - Portable Windows
================================================

Run "Launch Gielinor Companion Portable.cmd" to start in explicit portable
mode. You can also run "Gielinor Companion.exe --portable" from a command
prompt or shortcut.

Portable mode stores the SQLite database under portable-data beside the app.
It never uses or modifies the installed per-user database. Deleting the
portable-data directory permanently deletes the portable profiles, confirmed
quest status, holdings, cash, watchlists, acquisition costs, trade journal and
paper portfolio. Back up exports before deleting or moving that directory.

The runtime is local and read-only with respect to RuneScape. It does not log
in, control the game client, or place Grand Exchange offers. Public data still
requires internet access unless a validated cached snapshot is available.

If the app reports that its runtime is missing or corrupt, extract the complete
ZIP again. Do not run only the EXE by itself.
