# Version 1.1.0 real-data implementation plan and gap analysis

Status: implemented; local acceptance complete

Prepared: 2026-08-02

Baseline: `6ce3e55` from PR #16

Working branch: `agent/v1.1-resilience-maintenance`

## Baseline decision

PR #16 is the direct ancestor of the working branch. Its native startup,
supported Tauri detection, current-sidecar selection, missing-account error,
and no-demo-profile behaviour were preserved and validated before Version 1.1
work continued. The repository and Version 1 contracts were not rebuilt.

## Delivered vertical slices

1. Explicit runtime modes and fixture truthfulness.
2. Versioned private player data and selected-profile persistence.
3. Independent market/news adapters, provenance comparison, and staged first run.
4. Deterministic market intelligence, portfolio calculations, and manual plans.
5. Paper trading and no-look-ahead walk-forward backtesting.
6. Backward-compatible MCP tools and real-data desktop views.
7. Backend offline degradation, safety enforcement, live monitoring, and docs.
8. Full local release, native Windows, and live-provider acceptance.

## Deliberate limitations, not hidden gaps

- Standalone browser live development requires `corepack pnpm desktop:dev`; it
  does not silently fall back to fixtures.
- Public RS3 APIs cannot supply a complete bank, inventory, active offers, or
  quest state. Those remain local/manual and clearly labelled.
- Alt1 bank and GE-history OCR import is deferred; existing Alt1 behaviour is
  read-only and requires confirmation before local quest-state changes.
- Public GE sources are guide-price/history sources, not a live order book.
- macOS and Ubuntu native builds require the hosted CI matrix after push.
- Signed/notarised installers and optional local-AI daemon checks require
  maintainer infrastructure.

The evidence, counts, commands, and release limitations are recorded in
[the completion report](v1.1.0-completion.md).
