# Version 1.1.0 real-data implementation plan and gap analysis

Status: active implementation  
Prepared: 2026-08-02  
Baseline: `6ce3e55` from PR #16  
Working branch: `agent/v1.1-resilience-maintenance`

## Baseline decision

PR #16 is incorporated as the direct parent of the working branch. Its native
startup and live-player fixes are therefore part of every subsequent slice.
They are retained and covered by regression tests; the repository is not being
rebuilt.

## Current-state gaps

| Area                | Existing foundation                                                                            | Gap to close                                                                                                                                    |
| ------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Runtime boundary    | Supported Tauri detection, stdio MCP bridge, SQLite runtime                                    | Ordinary browser development silently selected mixed live/fixture data; explicit modes and permanent preview labelling were missing             |
| Public providers    | Jagex Hiscores and ItemDB/graph, Wiki quest and training providers, Weird Gloop bulk catalogue | Independent Weird Gloop history and news/event adapters, agreement metadata and fuller coverage reports are missing                             |
| First run           | Profile creation plus parallel catalogue refresh                                               | Staged source-aware retry/limited-mode workflow and market/news validation need completion                                                      |
| Private player data | Profiles and local quest status                                                                | Holdings snapshots, cash, acquisition cost, trade journal, watchlists, imports/exports, preferences and confirmed Alt1 suggestions are missing  |
| User-aware planning | Profile IDs exist on core planner inputs                                                       | Holdings subtraction and consistent selected-profile persistence are incomplete                                                                 |
| Market intelligence | Guide prices, history summaries, moving averages and volatility                                | Versioned deterministic scoring, recommendations, position sizing, order plans, portfolio analytics and provider comparison are missing         |
| Paper evaluation    | None                                                                                           | Paper portfolio, no-look-ahead backtests and walk-forward reports are missing                                                                   |
| MCP                 | Frozen 48-tool V1 contract plus 12 maintenance tools                                           | The additive real-data, private-state and market tool set is missing                                                                            |
| Desktop             | Existing quest, skill, GE and diagnostics views                                                | GE intelligence tabs, private-data editors and comprehensive source/freshness labels are missing                                                |
| Offline/resilience  | Retries, circuit breakers, cache fallback, recovery and scheduler                              | Backend offline enforcement must be connected to every new provider and recommendation confidence                                               |
| Tests/docs          | Broad V1.0 and resilience coverage                                                             | Focused real-data boundary, market, portfolio, backtest, safety and native integration gates plus the requested architecture/guides are missing |

## Buildable vertical slices

1. Enforce explicit runtime modes and fixture truthfulness; add native no-demo
   regression gates.
2. Add versioned private player data and selected-profile persistence through
   shared types, migration, repositories and MCP tools.
3. Add independent market/news adapters, provenance comparison and staged
   first-run synchronisation.
4. Add deterministic market intelligence, portfolio calculations and manual
   order plans.
5. Add paper trading and leakage-safe walk-forward backtesting.
6. Add the remaining MCP tools and real-data desktop views.
7. Complete offline degradation, provider monitoring, safety tests and the
   requested documentation.
8. Run every release gate and available native/live smoke test, then publish an
   evidence-based completion report.

Every slice must build and pass its focused deterministic tests before the next
slice starts. Preview, stale, retained, user-entered, screen-derived and live
data remain distinguishable throughout.
