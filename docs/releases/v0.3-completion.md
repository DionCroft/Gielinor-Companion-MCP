# Version 0.3 completion report

Completed and verified on 23 July 2026.

## Features implemented

- Authoritative standard and elite Invention XP curves.
- Current true 99/110/120 skill caps, including Construction 120, plus explicit
  virtual targets through standard level 126 and Invention level 150.
- Revision-aware RuneScape Wiki training synchronization for all 29 skills.
- Structured method level ranges, XP/hour ranges, published GP/hour ranges,
  intensity, AFK rating, membership, Ironman compatibility, requirements,
  confidence, uncertainty, timestamps, revisions, URLs, and hashes.
- Fastest, cheapest, balanced, and AFK deterministic method selection.
- Multi-stage plans with per-stage and total XP, hours, cost/profit, warnings,
  assumptions, daily-play completion dates, budgets, and target-date
  feasibility.
- Weekly XP/time goals, direct time and cost estimates, method comparisons, and
  quest XP reward comparisons.
- Explicit behavior for unreachable ranges, missing rates, missing GP data,
  quest gates, item ownership uncertainty, and Ironman exclusions.
- Reusable `refresh:training` command with a one-time pre-V0.3 backup and
  byte-for-byte profile-row integrity report.

## Architecture changes

- Extended shared schemas for training snapshots, sync status, strategies,
  stages, plans, and weekly goals.
- Added `TrainingMethodProvider` and `TrainingMethodRepository` ports.
- Added `LevellingPlannerService` to the model-independent core.
- Added `RuneScapeWikiTrainingProvider` with strict wikitext and rendered-table
  parsers.
- Added `SqliteTrainingMethodRepository` and additive migration 3.
- Composed the same planner behind local stdio MCP; no planning rule lives in
  the transport.

## Database migration

Migration 3 adds:

- `training_methods`, containing validated method JSON, searchable skill/level
  metadata, content hashes, source revisions, and timestamps;
- `training_sync_status`, containing retained count, covered skills, revision,
  last attempt/success, and safe failure information.

Migrations 1 and 2 are unchanged. Existing profile, cache, quest, and alias rows
remain compatible.

## Safety and limitations

- No gameplay input, client control, memory access, packet access, credential
  use, trading, or anti-cheat interaction exists.
- Rates are source estimates and remain ranges; the tool never promises an
  outcome.
- Cost/profit remains absent when the guide does not publish reliable GP data.
- Summoning and some other guide sections may be listable without a numeric
  hourly rate; these cannot produce a time plan.
- Ironman compatibility is unknown unless supported by source data.
- Bank, inventory, equipment ownership, temporary boosts, and actual player
  execution are not observed.
