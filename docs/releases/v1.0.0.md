# Gielinor Companion 1.0.0

Version 1.0 is the first stable public contract for the local-first,
read-only RuneScape 3 companion.

## Highlights

- Forty-eight stable MCP tools over local stdio and hosted Streamable HTTP.
- Stable profile export schema v1 with legacy v0 migration.
- Forward-only, transactional SQLite migrations through schema v5.
- Provider plugin API v1 with validation, priority, fallback, disagreement,
  offline, and health contracts.
- Complete quest, levelling, Grand Exchange, desktop/no-AI, Ollama, LM Studio,
  hosted, and optional Alt1 functionality from the verified 0.x milestones.
- npm package archives, Windows/macOS/Linux desktop bundles, hosted GHCR image,
  SPDX SBOM, SHA-256 checksums, and GitHub attestations produced by the release
  workflow.

## Upgrade

Back up the local database before an operator-managed upgrade. Normal startup
applies additive migrations in one transaction per version; profile export v1
does not change in this release. Review
[the migration policy](../architecture/migrations.md) and
[release integrity](../security/release-integrity.md).

## Compatibility

Existing Version 0.9 tools, inputs, structured result envelopes, profile
exports, and database rows remain supported. Provider plugins must declare
`apiVersion: 1`; the 0.9 interface was prerelease and now fails fast when a
different API version is supplied.

## Safety

No component controls RuneScape. There is no mouse/keyboard input, automated
combat/skilling/trading, memory reading, packet interception, credential
collection, CAPTCHA handling, or anti-cheat bypass. This is an unofficial
community project and is not affiliated with or endorsed by Jagex Ltd.
