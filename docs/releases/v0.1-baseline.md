# Version 0.1 verified baseline

Recorded on 23 July 2026 before Version 0.2 implementation.

## Preserved implementation

- Strict pnpm/TypeScript monorepo with shared Zod schemas.
- Core XP and profile services behind provider/repository ports.
- Resilient Jagex Hiscores and ItemDB adapters.
- Persistent stale-while-revalidate SQLite cache.
- SQLite schema version 1 with local player profiles.
- Eleven stdio MCP tools on `@modelcontextprotocol/sdk` 1.29.
- Profile import/export schema version 1.

## Verification

The unmodified Version 0.1 commit `81ef7bf` passed:

- `corepack pnpm exec prettier --check .`
- `corepack pnpm lint`
- `corepack pnpm typecheck`
- `corepack pnpm test`
- `corepack pnpm build`

All 31 deterministic tests in 8 files passed, including MCP protocol,
provider/cache, database, profile, and XP tests. Previously configured live
Hiscores and ItemDB smoke tests also passed.

## Compatibility decision

Version 0.2 extends the existing package boundaries and uses additive SQLite
migration 2. It does not replace Version 0.1 services, alter profile JSON, change
profile export schema version 1, or move the user's local database.
