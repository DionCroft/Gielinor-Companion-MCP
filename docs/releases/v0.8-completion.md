# Version 0.8 completion record

Date: 2026-07-23

## Outcome

Version 0.8 adds a policy-reviewed, optional Alt1 app for read-only RuneScape 3
quest guidance. It is disabled by default, operates locally, and remains
incapable of gameplay input. All existing MCP, desktop, hosted, local-AI, and
manual planning paths remain unchanged and usable without it.

## Features implemented

- Separate static `@gielinor/alt1-overlay` application.
- Explicit policy acknowledgement and per-field visibility for quest text,
  visible dialogue, and probable completion.
- Separate enable and connect actions plus pause, disconnect, and full revoke.
- Alt1 visible-main-chat OCR using only `pixel`; optional unclickable guidance
  uses `overlay`.
- Local schema-versioned guidance packs with step keyword matching and source
  links.
- Source labels, bounded confidence, redacted excerpts, and suggested guide
  steps.
- Completion detection that never auto-accepts; confirm/dismiss is manual and
  session-local.
- Manual pasted-text fallback when Alt1 or a supported screen is unavailable.
- Safe recovery from permission revocation, malformed captures, RuneScape
  disconnect/reconnect, and unsupported UI layouts.
- Original icon and interface with no copied RuneScape asset.
- Install, use, pause, uninstall, compatibility, policy, and privacy guidance.

## Architecture changes

The overlay is an outward adapter and does not enter the trusted core or MCP
dependency graph. Its capture controller accepts a narrow read-only driver; the
analyser and session are deterministic and testable without Alt1. A static
content-security policy prohibits outgoing connections.

## Database migrations

None. Overlay preferences are browser-local and contain only selected fields and
the guidance pack. No screen text enters SQLite or browser storage.

## MCP tools added or changed

None. All 48 existing tools and schemas remain backward compatible.

## Tests added

Twenty-seven deterministic overlay tests cover:

- default-disabled and explicit consent flow;
- per-field visibility;
- quest, dialogue, and completion recognition;
- ambiguous/false-positive confidence and manual confirmation;
- screen-text redaction and player/private-chat rejection;
- malformed observations and capture payloads;
- Alt1 minimum-version and permission contracts;
- runtime permission loss, disconnect/reconnect, unsupported screens, and safe
  capture failures;
- complete revoke and storage clearing;
- manifest permissions, exact library pin, CSP network denial, and static
  no-input/no-memory/no-packet guarantees;
- a browser-DOM flow through consent, connection, manual analysis, confirmation,
  disconnect, and revocation.

## External APIs and policy sources

- Pinned `alt1` JavaScript library 0.1.3.
- Alt1 runtime API 1.6.0 or later: installed/pixel/overlay/link state, visible
  capture, and unclickable overlay drawing.
- Current Jagex game rules, macro/client restrictions, and EULA.

The overlay makes no HTTP, WebSocket, game-world, or Jagex API request.

## Known limitations

- Alt1 supports Windows; manual fallback is cross-platform.
- The repository does not publish a trusted static overlay host.
- Pixel OCR depends on visible main-chat layout and can break after RuneScape UI
  changes.
- Dialogue outside the visible main chat is not captured automatically.
- Guide packs are pasted/imported locally; there is no live bridge from a
  profile or MCP client in this safety-first version.
- Alt1 and Gielinor Companion are unofficial third-party community projects.
  Policy can change, and users must review current Jagex terms.

## Security considerations

- Capture is opt-in twice: consent then connect.
- Every permission and runtime version is checked before reads.
- Raw pixels/text never persist or leave the page.
- Player/private-chat-shaped lines are discarded before analysis.
- The production CSP denies all network connections.
- The adapter exposes no input, memory, packet, process, socket, or trading
  capability.
- Completion signals cannot update companion or RuneScape state.
