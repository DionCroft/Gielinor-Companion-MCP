# Version 1.0 completion record

Final local release-branch validation completed on 2026-07-24. All mandatory
and release-specific gates passed.

## Features and architecture

- Stable 48-tool MCP contract with generated JSON Schema manifest.
- Stable profile export v1, provider plugin API v1, and SQLite schema/migration
  policy through version 5.
- Public npm manifests and clean packed-install smoke coverage.
- Cross-platform Tauri release matrix, hosted GHCR image, SPDX SBOM, SHA-256
  checksums, and GitHub provenance attestations.
- Complete client installation, privacy, integrity, example-workflow, and
  release documentation.

The domain, provider, persistence, stdio/HTTP transport, desktop, local-model,
and optional overlay boundaries remain those documented in
[the architecture overview](../architecture/overview.md).

## Database migrations

No Version 1.0 schema migration is required. Schema version 5 remains current.
Release tests create a fresh database and upgrade a version-1 database through
versions 2, 3, 4, and 5 while proving the original profile JSON survives.

## MCP tools

No tool was added, removed, or renamed. Inputs remain strict. Successful
structured content continues to use `data` plus source-stamped `meta`; public
errors retain stable code/message envelopes. The generated contract is
`data/contracts/mcp-tools-v1.json`.

## Validation status

- Formatting, ESLint, strict TypeScript, and every workspace build passed.
- Aggregate deterministic suites: 173 Node tests in 39 files plus 15 desktop
  DOM tests in 3 files.
- Focused suites passed: unit 104, integration 4, MCP 12, providers 39, local AI
  16, hosted 15, overlay 27, database 17, hardening 47, load 2, and stable
  release contracts 8. These counts overlap by design.
- End-to-end gates passed: 3 MCP workflows and 11 Playwright user journeys.
- Rust formatting, Clippy with warnings denied, and 4 native tests passed.
- Generated contract and every local Markdown link match the checked-in source.
- Seven npm archives packed with MIT licences; a clean temporary installation
  started the packed CLI and listed all 48 tools.
- A schema-1 database upgraded sequentially through schemas 2–5 without losing
  profile JSON; a fresh database opened at schema 5.
- The production container built and returned readiness as Version 1.0.0 under
  UID 10001, read-only rootfs, all capabilities dropped, and
  `no-new-privileges`.
- Windows x64 MSI and NSIS installers built successfully. Cross-platform native
  compilation is enforced by the Windows/macOS/Linux CI matrix; tag releases
  additionally produce DMG, AppImage, and DEB bundles.
- The locked Node audit reports no known vulnerabilities. RustSec remains a
  required GitHub check.
- The [accessibility review](../audits/accessibility-v1.0.md),
  [dependency audit](../security/dependency-audit.md), and
  [performance record](../performance/v1.0.md) are complete.

## External APIs

Version 1.0 adds no RuneScape data provider. Existing public Jagex and RuneScape
Wiki adapters remain validated and cached. Optional Ollama and LM Studio traffic
remains loopback-only.

## Security and privacy

The release workflow contains no private signing material. Checksums, SBOM, and
GitHub attestations are produced without long-lived keys. Platform signing uses
maintainer-controlled secrets only when available. Local use has no telemetry
or required account; hosted deployments retain their separate operator privacy
obligations.

## Known limitations and post-1.0 work

See [known limitations](../roadmap/known-limitations.md). Dynamic third-party
plugin discovery, OAuth-hosted profiles, durable distributed rate limits,
signed automatic updates, and broader independently executed platform matrices
remain post-1.0 candidates. The detailed 28-part handoff is the
[Version 1.0 final report](v1.0-final-report.md).
