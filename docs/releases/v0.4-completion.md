# Version 0.4 completion report

Completed and verified on 23 July 2026.

## Features implemented

- Search by canonical item name, normalized alias, Portuguese source alias, or
  numeric item ID.
- Current/previous guide prices, buy limits, high/low alchemy values, store
  values, membership, latest daily volume, price timestamps, and provenance
  where published.
- Ordered 24-hour through 180-day Jagex history and chart-ready results.
- Percentage change, 7/30/90-point moving averages, daily-return volatility,
  historical high/low, and 2.5-standard-deviation outliers.
- Fresh/stale/unknown catalogue and history states with retained validated
  history during bounded outages.
- Duplicate-aware, overflow-safe item-list, inventory, equipment, quest-shopping,
  and optional training-material valuation.
- JSON and spreadsheet-safe CSV export returned through MCP without arbitrary
  filesystem writes.
- Explicit unavailable fields for instant buy/high, instant sell/low, and
  historical volume instead of fabricated RS3 values.

## Architecture changes

- Extended shared schemas for catalogue snapshots, status, history, freshness,
  summaries, outliers, and valuations.
- Added `GrandExchangeDataProvider` and `PriceRepository` ports.
- Added model-independent `GrandExchangeService` analytics and valuation.
- Extended `JagexGrandExchangeProvider` with validated bulk catalogue and graph
  contracts while preserving the Version 0.1 detail lookup.
- Added `SqlitePriceRepository` and composed it behind the same stdio MCP
  service.

## Database migration

Additive migration 4 creates:

- `ge_items` for validated item JSON, hashes, price/source revisions, and
  searchable metadata;
- `ge_item_aliases` for normalized many-to-one and ambiguous aliases;
- `ge_price_history` for ordered daily price/average points and retrieval
  provenance;
- `ge_sync_status` for retained counts, revisions, attempts, successes, and
  safe errors.

Migrations 1-3 are unchanged. No player, quest, training, cache, or profile
export row is rewritten.

## Security considerations

- Every external response has timeout/retry handling and runtime validation.
- Complete catalogues are written in one transaction; suspicious data retains
  the previous valid snapshot.
- Valuation rejects unsafe integers and never automates a trade.
- CSV cells are quoted and formula-leading text is neutralized.
- No tool writes an arbitrary export path, accesses the client, or claims
  guaranteed profit.

## Known limitations

- Public RS3 sources do not provide a current instant order book.
- Historical graph points have no daily volume series.
- History is fetched on demand rather than preloaded for every catalogue item.
- Training-material repricing requires caller-supplied consumption quantities.
