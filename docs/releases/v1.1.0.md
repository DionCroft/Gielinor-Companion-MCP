# Gielinor Companion MCP 1.1.0

Version 1.1.0 is the real-data, account-aware player-intelligence release. It
retains the resilience and maintenance work while connecting the native desktop
consistently to validated providers, private local records, and deterministic
Grand Exchange analysis.

## Highlights

- Explicit runtime modes prevent native production from selecting demo data and
  label every browser preview.
- Real public Hiscores, revision-aware Wiki quest/training catalogues, Jagex GE
  detail/graph data, Weird Gloop RS3 catalogue/history/volume, and RuneScape news.
- Private local holdings, acquisition costs, trade journal, preferences,
  watchlists, selected profile, and paper portfolio in SQLite schema 8.
- Deterministic market scores, held-only sell candidates, manual order plans,
  portfolio analytics, and no-look-ahead delayed-fill backtests.
- Forty-five additive MCP 1.1 tools (93 total). The frozen 48-tool MCP 1.0
  prefix and schemas are unchanged.
- Eleven-stage first-run synchronisation, backend-enforced offline mode, and
  source/freshness-aware desktop market views.
- Bounded retries, circuit breakers, stale-cache fallback, invalid-data
  quarantine, verified recovery, diagnostics, scheduling, and read-only updates.
- Scheduled live Jagex, RuneScape Wiki, Weird Gloop, and GitHub contract
  monitoring stays separate from deterministic pull-request CI.

## Compatibility

- Existing MCP 1.0 names, order, strict schemas, and output fields remain compatible.
- Profile export remains schema 1 and provider plugin API remains version 1.
- Database schema 8 migrates forward while preserving profiles, quest progress,
  catalogues, cache, private records, and resilience state.
- Normal, Ironman, and Hardcore Ironman public Hiscores remain supported.

## Upgrade

Use Node.js 22 or 24:

```sh
git pull
corepack pnpm install --frozen-lockfile
corepack pnpm build
```

Existing file databases create a verified local backup before migration. Never
delete the database to upgrade; ambiguous recovery enters read-only safe mode.

## Truth, safety, and privacy

Hiscores are public snapshots, not a logged-in connection. Public APIs do not
provide a complete bank, inventory, quest log, or active offers; those values
are manual local records. RS3 prices are guide/history data, not a live order
book. Recommendations are estimates and may be wrong.

No feature generates mouse/keyboard input, reads client memory, intercepts
packets, asks for Jagex credentials, or places/edits/cancels a GE offer. Paper
trades are hypothetical and affect only their isolated local portfolio.
