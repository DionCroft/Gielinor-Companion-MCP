# Gielinor Companion MCP 1.1.0

Version 1.1.0 adds resilience, self-healing, automatic maintenance, diagnostics,
and read-only update awareness without changing the project's gameplay safety
boundary.

## Highlights

- Automatic first-run quest, training, and Grand Exchange catalogue population.
- Non-blocking startup stale checks and configurable persistent background
  refresh.
- A shared 62-code structured error registry with trace IDs and public
  redaction.
- Bounded retries, per-provider circuit breakers, validated provider fallback,
  visible stale-cache fallback, and invalid-data quarantine.
- Verified SQLite backup, migration rollback, interrupted-upgrade recovery,
  integrity checks, and read-only safe mode.
- A desktop Diagnostics centre with health, recovery history, targeted refresh,
  integrity check, redacted export, offline mode, update checks,
  expired-quarantine cleanup, and confirmed single-circuit reset.
- Twelve additive MCP 1.1 diagnostics and maintenance tools. The frozen 48-tool
  MCP 1.0 prefix is unchanged.
- A read-only GitHub Releases checker that never downloads or installs code.
- Weekly live Jagex, RuneScape Wiki, Grand Exchange, and GitHub contract
  monitoring with transient-versus-contract failure classification.
- Explicit Node.js 22 and 24 support and CI verification.

## Compatibility

- Existing MCP 1.0 tool names, ordering, strict input schemas, and existing
  output fields remain compatible.
- Profile export stays at schema version 1.
- Provider plugin API stays at version 1.
- Database schema 6 is a forward migration that preserves all existing profile,
  quest progress, catalogue, and valid cache rows.
- Normal, Ironman, and Hardcore Ironman public Hiscores remain supported.

## Upgrade

Source installations should use Node.js 22 or 24:

```sh
git pull
corepack pnpm install --frozen-lockfile
corepack pnpm build
```

Existing databases upgrade automatically through a verified local backup.
Never delete the database to perform this upgrade. If validation cannot complete
safely, the application preserves the original and enters read-only safe mode.

## Safety and privacy

Recovery is bounded, logged, observable, non-destructive by default, and limited
to the companion's local data and public providers. No mouse/keyboard control,
gameplay automation, memory reading, packet interception, credentials, CAPTCHA
handling, trading, or anti-cheat bypass was added.

Diagnostic and monitor artifacts exclude credentials, profiles, raw provider
payloads, private headers, absolute paths, prompts, and stack traces. The update
checker sends no player data and never executes release assets.
