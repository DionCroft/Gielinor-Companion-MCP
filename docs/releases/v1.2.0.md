# Version 1.2.0 — One-Click Launch and Live-Data Completion

Version 1.2.0 makes the native desktop a normal one-click application and makes
the source of every user-visible value explicit. It preserves all 93 Version
1.1 MCP tools, the frozen 48-tool Version 1.0 prefix, provider plugin API v1,
profile export v1, database schema 8, existing local data, and the read-only
RuneScape safety boundary.

## Downloads

- `Gielinor-Companion-Setup-1.2.0-x64.exe` — recommended Windows installer
- `Gielinor-Companion-1.2.0-x64.msi` — managed Windows environments
- `Gielinor-Companion-Portable-1.2.0-x64.zip` — isolated explicit portable mode
- `Gielinor-Companion-1.2.0-macos-<arch>.dmg`

- `SHA256SUMS.txt`, SPDX JSON SBOM, and GitHub artifact attestation

## Highlights

- Per-user NSIS setup with Start Menu/default desktop shortcut, final-page
  launch, normal uninstall registration, dynamic version, and data-preserving
  upgrades/uninstall.
- Single-instance focusing and a visible already-running message.
- Exact bundled local MCP runtime with actionable missing/corrupt-sidecar errors.
- Explicit `--portable` database/runtime isolation and portable ZIP.
- Secondary source-developer launcher with locked dependency detection,
  production-only launch, actionable errors, and diagnostic logs.
- Eight-origin machine-readable provenance model and consistent Live, Cached,
  Manual, Imported, Alt1 confirmed, Calculated, Preview, and Unavailable badges.
- Production entry graph isolated from preview fixtures and checked after build.
- Eleven-stage non-blocking first run with retries and safe limited mode.
- Dedicated Data Sources centre and redacted provenance export.
- Platform-aware read-only update recommendations and checksum-metadata status.

Hiscores are public snapshots, not an authenticated game-session feed. Public
RS3 Grand Exchange sources expose guide values and history, not a live order
book. Bank, inventory, cash pouch, active offers, completed transactions,
acquisition costs, complete quest state, and location remain manual, imported,
Alt1-confirmed, or Unavailable. The companion never places, edits, or cancels a
Grand Exchange offer and never automates gameplay.
