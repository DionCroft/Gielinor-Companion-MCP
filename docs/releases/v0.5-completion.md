# Version 0.5 completion report

Completed and verified on 23 July 2026.

## Features implemented

- Tauri 2/React first-run setup and a complete no-AI dashboard.
- Multiple local profiles with public-stat refresh and schema-versioned JSON
  import/export.
- Skills and exact target progress.
- Quest search, dependency-first route, manual checklist, and aggregated route
  shopping.
- Deterministic multi-stage levelling plans.
- GE item search, current guide value, 30-day analytics, freshness, and SVG
  history charts.
- Ad-hoc shopping valuation, local goals, data-source health, update status,
  settings, optional-AI preview, and about/legal views.
- Dark/light/system themes, compact mode, keyboard focus, skip navigation,
  reduced motion, responsive layouts, and explicit loading/error/empty states.

## Native architecture

- A two-command Tauri boundary reports runtime health and invokes companion
  tools.
- The bridge allows exactly the 48 documented MCP tools and never invokes a
  shell.
- Production builds bundle the MCP runtime, production dependencies, and a
  target-specific Node sidecar.
- CSP, prototype freezing, sanitized errors, and the `core:default` window
  capability keep the shell least-privilege.

## Verification

- React/Vitest: 10 tests across state, validation, and full application flows.
- Playwright: 8 Chromium journeys covering first-run, multiple profiles, quests,
  levelling, GE, offline mode, provider failure, and reload persistence.
- Rust: 3 tests covering the allowlist, sanitized errors, and a real
  deterministic MCP stdio call.
- Existing deterministic MCP/core/provider/database suite remains green.
- Strict TypeScript, ESLint, Prettier, Cargo fmt, and Clippy pass.
- Production React build succeeds.
- Windows x64 application and unsigned NSIS installer build successfully from
  the long OneDrive workspace path.

## Safety and limitations

- No gameplay input, client memory, packet access, trade placement, credentials,
  CAPTCHA handling, or anti-cheat bypass.
- Public prices remain guide values rather than guaranteed trades.
- Offline mode is retained-data behavior, not a host firewall.
- Development installers are unsigned; signed/notarized distribution remains
  Version 1.0 release work.

tool service while preserving full no-AI operation.
