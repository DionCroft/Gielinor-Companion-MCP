# Version 0.3 data sources

## XP thresholds and true skill caps

The deterministic XP module is checked against RuneScape Wiki
[`Experience/Table`](https://runescape.wiki/w/Experience/Table), revision
`37100263`, updated `2026-07-15T08:40:45Z`.

- Standard skills use the published RuneScape formula through virtual level 126.
- Invention uses the exact published elite-skill thresholds through virtual
  level 150; it does not use the standard formula.
- Level 99 is 13,034,431 XP on the standard curve.
- Level 110 is 38,737,661 XP on the standard curve.
- Level 120 is 104,273,167 XP on the standard curve and 80,618,654 XP for
  Invention.
- True caps are stored per skill as 99, 110, or 120. Construction is level 120
  following its July 2026 expansion.

The source revision is recorded in code and this document so a future cap or
curve update is reviewable.

## Training methods

`RuneScapeWikiTrainingProvider` reads the current members' training guide for
every one of the 29 skills. Shared combat guides are mapped to each affected
skill. The provider requests:

1. exact MediaWiki revision IDs, timestamps, and wikitext in one batch;
2. rendered HTML for those same revision IDs, in bounded batches of five.

Wikitext summary tables and level-range sections are preferred. Rendered tables
are used for values generated by Wiki templates, including compact rates such as
`150k`, multiple equipment scenarios, and published profit/loss per hour.
Named prose sections are a lower-confidence fallback. If a guide describes a
method but publishes no safely extractable hourly rate, the method remains
listable with an explicit missing-rate warning and cannot be used for a time
estimate.

Each stored method includes its page URL, page revision, source update time,
local check time, SHA-256 content hash, confidence, and uncertainty notes.
Snapshot metadata includes a deterministic digest of all source page revisions.

## Validation and replacement policy

- Levels must be within supported standard/Invention ranges.
- Numeric ranges must be positive and ordered.
- Parsed XP rates above 50,000,000 per hour are rejected as implausible parser
  output rather than silently accepted.
- Method IDs must be unique and all 29 skills must be represented.
- Empty snapshots fail.
- Once at least 20 methods exist, a replacement below 80% of the retained count
  fails as suspiciously incomplete.
- Domain validation finishes before the SQLite transaction begins.
- A failed attempt records a safe status while preserving the prior methods and
  last-success metadata.

Refresh is operator initiated with `refresh_training_data` or
`corepack pnpm refresh:training`. There is no background schedule in Version
0.3.

## Interpretation

Training rates are estimates, not guarantees. Equipment, boosts, attention,
banking, mistakes, unlocks, updates, and market conditions can change actual
results. The planner retains published minimum/maximum values and calculates
best/worst time ranges. GP data is used only where a source table provides it;
otherwise cost and profit remain unknown.

Ironman compatibility defaults to unknown unless a source supports a stronger
claim. Quest requirements found in a method section are checked against the
profile's manual quest status. Item and equipment ownership are not inferred.

## Privacy

Wiki requests send only the configured descriptive User-Agent. No profile ID,
display name, skill snapshot, quest status, inventory, credential, or RuneScape
client data is sent to the Wiki.
