# Version 0.4 Grand Exchange data sources

Verified on 23 July 2026.

## Official Jagex ItemDB detail endpoint

Purpose: preserve the Version 0.1 single-item current guide-price lookup.

Endpoint:
`https://secure.runescape.com/m=itemdb_rs/api/catalogue/detail.json?item=<id>`.

The adapter validates the requested ID, canonical name, optional membership and
description fields, and compact current price. Results use the persistent
stale-while-revalidate cache: five minutes fresh and one additional hour stale
by default. No authentication is required. HTTP failures, rate limiting,
timeouts, missing items, unsupported compact prices, and malformed JSON remain
distinct errors.

## Official Jagex ItemDB graph

Purpose: daily RS3 guide-price history for the previous 180 days.

Endpoint:
`https://secure.runescape.com/m=itemdb_rs/api/graph/<item-id>.json`.

The response contains `daily` guide prices and Jagex's published `average`
series. Unix-millisecond keys are validated and ordered. A zero daily value
means no usable price and is omitted. History is cached for six hours and can be
retained as an explicitly stale fallback for seven days when refresh fails.
User-selected 24-hour, 7-, 30-, 90-, and 180-day ranges are filtered locally.

The graph does not publish instant buy/sell prices or historical daily volume.
The project does not infer either.

## RuneScape Wiki Grand Exchange Market Watch bulk dump

Purpose: searchable catalogue, names/aliases, current and previous guide prices,
buy limits, high/low alchemy values, store value, membership, and latest daily
volume where available.

Endpoint:
`https://chisel.weirdgloop.org/gazproj/gazbot/rs_dump.json`.

The RuneScape Wiki documents this as the JSON dump generated by its Grand
Exchange Market Watch updater. `%JAGEX_TIMESTAMP%` is retained as the source
revision and price timestamp; retrieval time is stored separately. Portuguese
canonical names become searchable aliases when supplied. Each normalized item
has a SHA-256 content hash.

No authentication is required. The service asks clients to use a descriptive
User-Agent and does not publish a fixed request quota. Gielinor Companion makes
one bulk request only when the user explicitly refreshes price data. A response
with malformed entries, duplicate IDs, missing timestamp metadata, or fewer
than 1,000 items is rejected. SQLite independently rejects a replacement below
80% of an established 1,000+ item catalogue.

## Derived analytics

All analytics are deterministic over validated guide-price points:

- percentage change uses the first and last usable point in the requested range;
- moving averages use the latest 7, 30, or 90 available daily points;
- volatility is the population standard deviation of consecutive daily
  percentage returns, expressed as a percentage;
- historical high/low use the requested range;
- outliers are points at least 2.5 population standard deviations from the
  range mean.

These are descriptive statistics, not predictions or profit guarantees.

images or game assets are bundled. Jagex and RuneScape marks remain subject to
their owners' terms; the RuneScape Wiki source and service terms must be
respected by redistributors. Provider URLs and timestamps remain visible for
