# Version 1.0 performance record

Measured on 2026-07-24 on Windows x64 with Node 24.18.0. Results are regression
evidence, not hosted capacity guarantees.

| Workload                                         |          Result |
| ------------------------------------------------ | --------------: |
| Insert 5,000 validated in-memory SQLite profiles |        78.72 ms |
| Read and parse 5,000 profiles                    |        15.69 ms |
| Observed heap growth                             | 6,912,616 bytes |

The dedicated load gate also passed:

- 2,000 profile writes/list under 5 seconds and 64 MiB heap growth;
- a 1,000-node linear quest graph under 2 seconds;
- 250 hosted liveness requests at concurrency 25 under 5 seconds and 64 MiB
  heap growth;
- database and hosted load tests: 2/2 passed;
- concurrent identical HTTP/cache refreshes remain coalesced and failure
  releases the lock.
