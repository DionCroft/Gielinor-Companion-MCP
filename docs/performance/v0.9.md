# Version 0.9 performance record

Measured on 2026-07-24 on Windows x64 with Node 24.18.0. These are regression
budgets, not hosted capacity claims.

`corepack pnpm profile:performance`:

| Workload                                         |          Result |
| ------------------------------------------------ | --------------: |
| Insert 5,000 validated in-memory SQLite profiles |        83.05 ms |
| Read and parse 5,000 profiles                    |        17.35 ms |
| Observed heap growth                             | 6,876,280 bytes |

Deterministic tests additionally verified:

- 2,000 profile writes/list under 5 seconds and 64 MiB heap growth;
- a 1,000-node linear quest graph under 2 seconds;
- 250 hosted liveness requests at concurrency 25 under 5 seconds and 64 MiB
  heap growth;
- concurrent identical cache and HTTP refreshes perform one loader/request;
- cache locks release after failure and SQLite writes recover after a lock.

CI thresholds are deliberately much looser than the recorded local results to
avoid treating shared-runner noise as a regression.
