# Installation guides

Choose one surface:

- [One-click Windows installer](one-click-windows.md) for normal Windows users.
- [Portable Windows mode](portable-windows.md) for an explicitly isolated archive.
- [Local stdio MCP](local-mcp.md) for standards-compliant desktop/CLI clients.
- [Claude Desktop](claude-desktop.md).
- [Claude Code](claude-code.md).
- [LM Studio](lm-studio.md) as an MCP host or local model provider.
- [Ollama](ollama.md) as an optional desktop local model provider.
- [Standalone desktop](desktop.md) for the complete no-AI dashboard.
- [Hosted MCP](hosted.md) for a self-operated HTTPS service.
- [ChatGPT](chatgpt.md) for the anonymous public hosted tool surface where the
  current plan and workspace support custom MCP apps.
- [Optional Alt1 overlay](alt1-overlay.md) for consent-based read-only visible
  main-chat guidance.

No standard local installation needs a paid API, Jagex credentials, or a
language model.
